# Tugas Pewarisan dan Polimorfisme

Program simulasi rekening bank. Class Bank_2 sebagai induk,
Tabungan dan Giro sebagai turunan, dan ArrayList untuk menyimpan
daftar rekening serta riwayat transaksi.

## Cara menjalankan
javac *.java
java DemoBank

## Library tambahan
Tidak ada, hanya java.util.ArrayList.
